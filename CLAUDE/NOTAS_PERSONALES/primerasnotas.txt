Es un software para mi papa, es dueño de un negocio y lo gestiona él solo.

Cuando llega un cliente, puede comprar productos o solicitar accesorios al dejar un dispositivo. A la hora de retirar un dispositivo que ser reparó, también puede hacer compra de un producto o solicitar accesorios para el dispositivo a retirar

Hay dos tipos de trabajos: Servicio técnico y venta de productos.

Cuando un cliente viene a un servicio técnico, se genera una orden de trabajo la cual contiene los servicios que se deben realizar al/los dispositivo en particular y si hubo un pago total o parcial. Además a esa orden se agregan productos que el cliente va a llevarse  cuando cuando venga a retirar el dispositivo reparado (accesorios). Cuando el cliente viene a retirar el dispositivo, se concreta la transacción, se paga el total (si queda deuda pendiente), se pueden agregar mas productos a la orden inicial y finalmente cuando se completa el total de la transacción se genera una Factura, que es un registro de la transaccion finalizada 

Cuando viene un cliente viene a comprar un producto, simplemente se hace la factura de la transacción finalizada con el producto vendido, sin orden de compra. El cliente no recibe ningun “ticket”.

## Etapa creacion de ordenes de trabajo

Se deben poder hacer ordenes de trabajo. Estas ordenes de trabajo registran que hay un trabajo por hacer, estas registran:
Fecha que se recibe el pedido, el dispositivo (se debe poseer base de datos de marcas y modelos del celular), nombre del cliente, telefono del cliente, daño o cosa a hacerle a la maquina (pc o computadora) , el tipo de bloqueo (patron, pin, contraseña, nada), fecha, si dejó seña, monto base (luego puede ser distinto si el cliente decide pagar con metodos que tienen montos adicionales), nombre y firma del cliente (no se como hacerla).
 La orden de trabajo tiene dos partes, una se la tiene que quedar el empleado y una parte debe tener  recortado para que le quede al cliente. El recortado tiene la firma del empleado, fecha en el que dejó el dispositivo, nombre del cliente y un disclaimer que diga que luego de 30 dias no hay reclamos. 

La primera parte de la seña se puede hacer con un metodo de pago y la segunda parte se puede hacer con otro metodo de pago distinto. Los montos de cobro extra por tarjeta se ven por separado

La orden de trabajo que utiliza mi papa registra si el cliente adquirió cables, cargadores, soportes, luces, vidrios templados, etc. Hay que analizar como registrar esta informacion

Es importante recalcar la importancia de poder tener una base de datos completa de celulares, modelos, marcas para luego tener registro de estadisticas.

## Etapa de facturacion

Debe haber un apartado para el sistema de facturacion, tanto para la venta directa de productos como para concretar un servicio+producto.

La facturacion es el registro que se hace para modificar el stock y lo que finalmente modificaría la base de datos (creo).

La facturación debería tener en cuenta que el empleado puede recibir una orden para un trabajo de arreglo de celular pero se pueden agregar un cable, un templado, etc (accesorios). La facturacion es para registro del dueño, debe figurar si pago con efectivo, transferencia, tarjeta, etc. Cuando es de contado el empleado no lo factura ante el afip porque con eso le paga a proveedores. Lo que el dueño recibe por transferencia o por tarjeta mi papa lo factura todo lo que mas puede (no siempre lo factura). Cuando se recibe un pago por transferencia él quiere poder decidir que hacer con ese registro de pago, el puede decidir si ese pago va a registrarse solo en la base de datos o si además de registrarlo en la base de datos el quiere facturarlo automaticamentre al ARCA yo debo programar esa parte.

## Registro y estadisticas

Entonces los celulares se deben poder registrar cuales se arreglaron y cuales no, se debe abrir un menu desplegable que aparezcan todos los celulares, el objetivo es poder seleccionar un rango y revisar estadisticas de ese plazo. 

En esos plazos seleccionados se podrá ver cuantos telefonos de cuales marcas se arreglaron, cuantos modulos, cuantas baterias, cuantas computadoras. Todas las estadisticas posibles para poder saber que repuestos conviene comprar para tener en stock. Tiene que ser muy versatil ya que se debe poder filtrar por “vendi x samsung en estas fechas”, “arreglé tantos samsung en estas fechas”, “hice tantas reparaciones de notebooks en este tiempo”…

 La pc no debe diferenciarse en marca y modelo (si existe una base de datos ya armada de notebooks mejor) pero no es tan urgente.

Las estadisticas deben poseer informacion de cuanto se le pagó a cada proveedor. Cuanto dinero se movió, cuanto se pagó con cada metodo de pago a cada proveedor.

Las estadisticas deben poder indicar cuanto ha pagado cada cliente en total desde que pertenece al negocio (Se me ocurren varios problemas con esto, luego pensar).
